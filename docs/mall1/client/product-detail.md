# [PRD] 상품 상세 페이지 (`/products/[id]`)

## 1. 개요
* **목적**: 상품의 상세 정보(이미지, 가격, 스펙)를 제공하고, 옵션 선택 및 수량 조절을 통해 장바구니 담기 또는 즉시 구매 유도
* **경로**: `/products/[id]`

---

## 2. 화면 구성 및 상세 요구사항

### 2.1. 상품 갤러리 (Left Column)
* **UI**: 메인 대표 이미지(`mainImageUrl`) 및 서브 썸네일 리스트(`subImageUrls`)
* **동작**: 썸네일 클릭 시 메인 이미지 변경

### 2.2. 상품 구매 정보 영역 (Right Column)
* **기본 정보**: 상품명, 정상가, 할인가, 할인율
* **옵션 선택기**:
  * `ProductOption[]` 데이터를 기반으로 옵션(색상, 사이즈 등) 선택 드롭다운/버튼 제공
  * 옵션 선택 시 추가 금액(`surcharge`) 반영
* **수량 제어**:
  * 수량 증감 버튼 (+ / -), 최소 1개 이상
* **총 결제 금액 계산**:
  * `(선택 옵션 추가금 + discountedPrice) * 수량` 동적 계산
* **C2A 버튼**:
  * `[장바구니 담기]`: 선택된 옵션/수량 정보를 장바구니(State/Storage)에 저장 후 토스트 메시지/알림
  * `[바로 구매하기]`: 선택된 주문 정보를 가지고 `/checkout` 이동

### 2.3. 상세 설명 및 정책 탭 (Bottom Area)
* **상세 정보**: HTML/Markdown 기반 상세 이미지 및 텍스트 정보
* **배송/교환/반품 안내**: 공통 배송 정책 및 환불 조건 표시
