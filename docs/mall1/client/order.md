# [PRD] Order : 장바구니 (`/cart`) & 주문/결제 (`/checkout`)

## 1. 개요
* **목적**: 사용자가 선택한 상품을 관리하고, 주소/배송 정보 입력 및 PG사 결제를 거쳐 주문을 완료하는 흐름 구현
* **경로**: `/cart`, `/checkout`, `/order/success`

---

## 2. 화면 구성 및 상세 요구사항

### 2.1. 장바구니 페이지 (`/cart`)
* **상품 관리 리스트**:
  * 선택 체크박스 (전체 선택 / 개별 선택)
  * 상품 이미지, 상품명, 선택 옵션명, 옵션 추가금 반영 단가
  * 수량 증감 버튼 (+ / -) 및 삭제 버튼
* **주문 금액 요약 (Order Summary)**:
  * 선택된 상품 총 금액 계산
  * 배송비 정책 반영 (예: 50,000원 이상 무료배송, 미만 시 3,000원)
  * 최종 결제 예정 금액 명시
* **C2A**: `[선택 상품 주문하기]` -> `/checkout` 이동 (선택된 아이템 정보 전달)

### 2.2. 주문/결제 페이지 (`/checkout`)
* **주문 상품 확인**: 결제 예정 상품 요약 정보 노출
* **배송지 정보 입력**:
  * 수령인 이름, 연락처, 배송지 주소(우편번호 API 연동 지점), 배송 메모
* **결제 수단 선택**:
  * 신용/체크카드, 간편결제(카카오페이, 토스페이 등)
* **결제 실행**:
  * 약관 동의 체크 후 PG 결제 모달/API 호출
  * 결제 성공 시 `/order/success`로 라우팅
