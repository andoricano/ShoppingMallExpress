# [PRD-PROD-00] 어드민 상품 모듈 공통 정책 (Common Policy)

## 1. 문서 개요

상품 관리 모듈(`PRD-PROD-01` ~ `PRD-PROD-03`)에서 공통으로 사용하는 상품 상태, 데이터 관리, UI/UX 및 권한 정책을 정의합니다.

---

## 2. 상품 및 데이터 정책

### 2.1 상품 상태

| 상태 | 설명 | Client 노출 | 구매 |
| :--- | :--- | :---: | :---: |
| `DISPLAY` | 정상 진열 및 판매 | O | O |
| `HIDDEN` | 판매자가 전시를 숨김 | X | X |
| `SOLD_OUT` | 품절 상태 | O | X |
| `DELETED` | 삭제된 상품 | X | X |

- `SOLD_OUT`은 원천 재고에 따라 자동 처리할 수 있으며, 어드민에서 수동 설정할 수도 있습니다.
- `SOLD_OUT` 상품은 재고가 다시 확보되어도 자동으로 `DISPLAY`로 복구하지 않습니다.
- `HIDDEN`은 상품 전시 상태이며 Inventory의 재고 상태와 별도로 관리합니다.

### 2.2 할인

- 할인 유형: `PERCENT`, `FIXED`
- 할인 기간을 지정할 수 있으며, 기간이 없으면 상시 할인으로 처리합니다.

### 2.3 카테고리

- 카테고리는 최대 3단계(`DEPTH_1` ~ `DEPTH_3`)로 구성합니다.
- 하나의 상품은 여러 카테고리에 매핑할 수 있습니다.
- 매핑된 카테고리 중 하나를 대표 카테고리로 지정할 수 있습니다.

### 2.4 재고 관리

- Product는 Inventory SKU를 상품 옵션에 매핑합니다.
- Product에서는 원천 재고를 직접 수정하지 않고 조회만 제공합니다.
- 실제 재고 차감 및 복구는 Order에서 처리합니다.

---

## 3. 공통 UI/UX 정책

- 목록 조회는 Skeleton UI를 사용합니다.
- 저장, 수정, 삭제 처리 중에는 로딩 상태를 표시하고 중복 요청을 차단합니다.
- 삭제 등 파괴적 액션은 Confirm Modal을 사용합니다.
- 상품 등록/수정 중 저장하지 않은 변경사항이 있으면 페이지 이탈 시 경고합니다.
- 검색 입력은 300ms Debounce를 적용합니다.
- 금액 및 숫자 입력은 숫자 형식 검증을 적용합니다.

---

## 4. 권한 정책

| 기능 | Super Admin | Master Seller | Product Operator | Read-Only Admin |
| :--- | :---: | :---: | :---: | :---: |
| 상품 조회 | O | O | O | O |
| 상품 등록/수정 | O | O | O | X |
| 상품 일괄 관리 | O | O | O | X |
| 상품 삭제 | O | O | X | X |
| 카테고리 관리 | O | O | X | X |

- UI에서 권한이 없는 기능은 비활성화할 수 있습니다.
- 실제 권한 검증은 서버 API에서도 수행합니다.

---

## 5. 공통 API 예외 처리

| HTTP | 처리 |
| :--- | :--- |
| `400` | 잘못된 요청 또는 Validation 오류 |
| `401` | 인증 실패 → 로그인 |
| `403` | 권한 없음 → 현재 페이지 유지 및 안내 |
| `404` | 대상 데이터 없음 |
| `409` | 상태 충돌 또는 동시 수정 |
| `500` | 서버 오류 안내 |
