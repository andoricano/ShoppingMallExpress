# [PRD] Admin 메인 대시보드 모듈 (Admin Main Navigation Hub)

## 1. 개요 (Overview)
본 문서는 쇼핑몰 관리자(Admin)가 로그인 후 가장 먼저 접하는 메인 대시보드 화면에 대한 PRD입니다. **쇼핑몰의 주요 핵심 기능(디자인/레이아웃, 주문 배송, 취소/환불, 매출 통계, 재고, 상품, 회원 관리)의 핵심 현황(건수, 썸네일 등)을 카드 형태로 직관적으로 표기**하고, 클릭 시 해당 상세 관리 페이지로 바로 진입하도록 돕는 **'네비게이션 허브(Navigation Hub)'** 역할을 수행합니다. 추후 매출 그래프나 상세 통계 위젯을 유연하게 추가할 수 있도록 확장성을 구비합니다.

---

## 2. 대시보드 진입 카드 구성 (Dashboard Quick Cards)

### 2.0 Client Page 디자인 및 레이아웃 관리 진입 카드 (Storefront Design & Layout)
- **주요 표시 정보**: 현재 적용 중인 `메인 테마/레이아웃 이름` 및 `최종 수정일시` (예: "기본 테마 (2026.08.24 수정)")
- **클릭 동작**: 클릭 시 `클라이언트 디자인/레이아웃 관리 페이지(/admin/design)`로 이동.

### 2.1 주문/배송 관리 진입 카드 (Order & Delivery)
- **주요 표시 정보**: 배송 처리 대기 중인 `신규 주문 건수` (예: "미배송 12건")
- **클릭 동작**: 클릭 시 `주문/배송 관리 페이지(/admin/orders)`로 이동.

### 2.2 환불/취소 관리 진입 카드 (Refund & Claim)
- **주요 표시 정보**: 승인 대기 중인 `취소/반품 요청 건수` (예: "취소/반품 3건", 필요 시 경고 색상 강조)
- **클릭 동작**: 클릭 시 `취소/환불 관리 페이지(/admin/claims)`로 이동.

### 2.3 가게 매출 통계 진입 카드 (Sales Overview)
- **주요 표시 정보**: 오늘/이번 달 `누적 매출액` 및 `총 결제 건수` 요약 텍스트
- **클릭 동작**: 클릭 시 `매출 분석/통계 페이지(/admin/analytics)`로 이동.

### 2.4 재고 관리 진입 카드 (Inventory)
- **주요 표시 정보**: `품절 임박 상품` 또는 `품절 상품` 1~2개의 **대표 썸네일** 및 잔여 재고 수 표시 (예: "품절 임박 4개")
- **클릭 동작**: 클릭 시 `재고 관리 페이지(/admin/inventory)`로 이동.

### 2.5 상품 관리 진입 카드 (Product)
- **주요 표시 정보**: 현재 `판매 중인 총 상품 수` 및 대표 상품 **썸네일**
- **클릭 동작**: 클릭 시 `상품 관리 페이지(/admin/products)`로 이동.

### 2.6 회원 관리 진입 카드 (User Management)
- **주요 표시 정보**: `전체 회원 수` 및 `오늘 신규 가입자 수` (예: "신규 가입 +8명")
- **클릭 동작**: 클릭 시 `회원 관리 페이지(/admin/users)`로 이동.

## 3. 기능 요구사항 (Functional Requirements)

### 3.1 메인 대시보드 레이아웃 (Card Grid System)
- **그리드 레이아웃**: 디자인, 매출, 주문/클레임, 재고, 상품, 회원 관리 카드를 Grid(2x4 또는 3x3) 형태로 시각적으로 균형 있게 배치.
- **카드 구성 요소**:
  - **카테고리 타이틀 및 아이콘**: 각 모듈을 직관적으로 알아볼 수 있는 아이콘
  - **요약 지표/썸네일**: 숫자로 된 핵심 건수, 텍스트 요약 또는 대표 썸네일 이미지
  - **이동 화살표(CTA)**: 클릭 가능함을 암시하는 '바로가기 →' 영역

### 3.2 인터랙션 및 피드백 (Hover & Quick Jump)
- **Hover Effect**: 각 카드 마우스 오버 시 입체감(Shadow, Hover border)을 주어 클릭 가능한 버튼 형태임을 강조.
- **신규/긴급 알림 배지 (Alert Badge)**: `취소/반품` 또는 `품절 임박` 건수가 1건 이상일 경우 카드 우측 상단에 붉은색 알림 배지 노출.

---

## 4. 비기능 및 UX 요구사항 (Non-Functional Requirements)

- **직관적인 UX (Fast Navigation)**:
  - 대시보드 내에서 복잡한 입력/수정을 거치지 않고, 오직 현황 파악 후 **1-Click**으로 원하는 관리 페이지로 빠르게 이동하는 데에만 집중.
- **모듈식 확장성 (Extensibility)**:
  - 각 카드는 독립적인 덤프 컴포넌트(DashboardCard) 형태로 작성하여, 추후 매출 차트나 신규 위젯이 추가되어도 레이아웃 변경이 용이하도록 구성.
