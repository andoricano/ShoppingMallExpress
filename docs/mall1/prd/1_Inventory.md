# [PRD] 재고 관리 모듈 (Inventory Management) - Admin Only

> 본 모듈은 **100% 어드민(Admin Web/App) 전용 모듈**입니다.
>
> 일반 구매자는 본 모듈에 직접 접근할 수 없으며, 상품 및 주문 모듈을 통한 재고 연동만 수행합니다.

---

## 1. 개요 (Overview)

어드민에서 SKU별 현재 재고를 관리하고,
수동 입출고 및 주문에 따른 재고 차감/복구를 처리합니다.

---

## 2. 관리 데이터 (Data Scope)

### 2.1 SKU 정보

* SKU ID
* Item ID
* SKU 코드
* SKU 메타 정보

### 2.2 재고 정보

* 현재 재고 수량
* 활성 상태

---

## 3. 기능 요구사항 (Functional Requirements)

### 3.1 재고 조회

* SKU별 현재 재고 수량 조회
* Item/SKU 기준 검색 및 조회

### 3.2 재고 수동 조정

* 어드민이 재고를 수동으로 입고/출고 처리
* 조정 결과를 재고에 반영

### 3.3 주문 연동

* 주문에 따른 재고 차감
* 주문 취소 등에 따른 재고 복구
* 재고 부족 시 차감 처리 거부

### 3.4 재고 비활성화

* 더 이상 사용하지 않는 SKU는 물리 삭제하지 않고 비활성화
* 비활성화된 SKU는 신규 재고 변동 대상에서 제외
* 기존 재고는 유지

---

## 4. 권한 (Permissions)

* **Super Admin**: 모든 재고 조회 및 관리
* **Store Operator**: 허용된 재고 조회 및 관리
* **Customer**: 접근 불가

---

## 5. 비기능 요구사항 (Non-Functional Requirements)

### 5.1 접근 제어

* 재고 API는 어드민 권한을 가진 사용자만 접근할 수 있어야 합니다.
* 구매자용 API와 어드민용 API를 구분합니다.

### 5.2 데이터 일관성

* 재고 차감/복구 및 수동 조정은 DB 트랜잭션으로 처리합니다.
* 동시에 재고가 변경되는 경우에도 재고가 음수가 되지 않아야 합니다.
