# [PRD] 재고 관리 모듈 (Inventory Management) - Admin Only

> 본 모듈은 **100% 어드민(Admin Web/App) 전용 모듈**입니다.
>
> 일반 구매자는 본 모듈에 직접 접근할 수 없으며, 주문 모듈을 통한 재고 연동만 수행합니다.

---

## 1. 개요

어드민에서 SKU별 현재 재고를 관리하고, 수동 입출고 및 주문에 따른 재고 차감/복구를 처리합니다.

하나의 Inventory는 하나의 **개별 SKU 판매 단위**를 나타냅니다.

Inventory의 활성 상태는 해당 SKU의 판매 가능 여부에 영향을 줍니다.

---

## 2. 관리 데이터

### 2.1 SKU 정보

* SKU ID
* SKU 코드
* SKU 메타 정보 (`meta`)

SKU 메타 정보는 상품 종류에 따라 자유롭게 구성할 수 있으며, 여러 속성을 동시에 가질 수 있습니다.

대표 속성:

* `measure`
* `color`
* `model`
* `unit`
* 기타 SKU 구분 정보

### 2.2 재고 정보

* 현재 재고 수량
* 활성 상태

---

## 3. 기능 요구사항

### 3.1 재고 조회

* SKU별 현재 재고 수량 조회
* SKU 코드 기준 검색 및 조회
* SKU 메타 정보 기준 조회
* 활성/비활성 Inventory 조회

### 3.2 재고 등록

* 새로운 SKU 재고 등록
* SKU 코드, 초기 재고 수량, SKU 메타 정보 등록
* 신규 Inventory는 기본적으로 활성 상태로 생성
* 동일 SKU 중복 등록 방지

### 3.3 재고 수동 조정

* 수동 입고 및 출고
* 조정된 수량은 현재 재고에 즉시 반영
* 재고가 0 미만이 되도록 조정 금지
* 비활성 Inventory는 수동 조정 대상에서 제외

### 3.4 주문 연동

* 주문에 따라 선택된 SKU의 재고 차감
* 주문 취소 등에 따른 재고 복구
* 재고 부족 시 차감 거부
* 비활성 Inventory는 신규 주문 대상에서 제외

### 3.5 재고 비활성화

* 더 이상 판매하지 않는 SKU는 `isActive = false`로 비활성화
* 비활성 Inventory는 신규 주문 대상에서 제외
* 비활성 Inventory는 Inventory API로만 직접 수정 가능
* 활성 Inventory에 대한 비활성화시 Product를 아예 보이지도 않게 함

### 3.6 재고 활성화

* 재활성화된 Inventory는 다시 재고 변동 및 주문 대상이 될 수 있음

### 3.7 재고 삭제

* 비활성 Inventory만 삭제 가능
* 활성 Inventory는 삭제 불가
* 기존 주문 등에서 참조되는 Inventory는 삭제 불가
* 삭제된 Inventory는 신규 주문 및 재고 처리 대상이 될 수 없음

---

## 4. 권한

* **Super Admin**: 모든 재고 조회 및 관리
* **Store Operator**: 허용된 재고 조회 및 관리
* **Customer**: 접근 불가

---

## 5. 비기능 요구사항

### 5.1 접근 제어

* 재고 API는 어드민 권한 사용자만 접근 가능
* 구매자용 API와 어드민용 API 구분
* Client에서는 Inventory 직접 수정 불가

### 5.2 데이터 일관성

* 재고 차감, 복구 및 수동 조정은 DB 트랜잭션으로 처리
* 동시 재고 변경 상황에서도 재고 음수 방지
* 재고 상태와 SKU 정보의 무결성 보장
* 주문에서 참조되는 SKU 및 재고 데이터의 무결성 보장
