# [PRD] 상품 관리 모듈 (Product Management) - Admin Focused

> 본 모듈은 **상품 정보를 관리하고 구매자에게 판매 상품 정보를 제공하는 모듈**입니다.
>
> 상품의 재고 수량은 **Inventory 모듈**에서 관리하며, 본 모듈에서는 재고 자체를 관리하지 않습니다.

---

## 1. 개요 (Overview)

어드민에서 판매 상품의 기본 정보와 가격, 판매 Item을 관리하고,
구매자에게 판매 가능한 상품 정보를 Read-Only로 제공합니다.

---

## 2. 관리 데이터 (Data Scope)

### 2.1 상품 정보

* Product ID
* 상품명
* 상품 코드
* 대표 이미지
* 추가 이미지
* 상품 설명
* 가격
* 활성 상태
* 노출 상태

### 2.2 상품 Item

* Item ID
* 연결된 SKU ID
* 옵션 정보
* 옵션별 추가 가격

> SKU의 재고 수량 및 재고 상태는 Inventory 모듈에서 관리합니다.

---

## 3. 기능 요구사항 (Functional Requirements)

### 3.1 상품 등록

* 어드민이 상품을 등록할 수 있어야 합니다.
* 상품명, 이미지, 설명, 가격 등의 기본 정보를 등록할 수 있어야 합니다.
* 상품에 판매 Item을 연결할 수 있어야 합니다.
* 상품의 활성 및 노출 여부를 설정할 수 있어야 합니다.

### 3.2 상품 조회

#### Admin

* 전체 상품 목록 조회
* 상품명 및 상품 코드 검색
* 상품 상세 정보 조회
* 연결된 Item 정보 조회

#### Client

* 활성화 및 노출된 상품 조회
* 상품 목록 및 상세 정보 조회
* 상품 정보를 Read-Only로 조회

### 3.3 상품 수정

* 상품명, 이미지, 설명, 가격 등의 정보를 수정할 수 있어야 합니다.
* 상품의 Item 연결 및 옵션 정보를 수정할 수 있어야 합니다.
* 활성 및 노출 상태를 변경할 수 있어야 합니다.

### 3.4 상품 비활성화

* 더 이상 판매하지 않는 상품은 물리 삭제하지 않고 비활성화합니다.
* 비활성화된 상품은 Client에 노출하지 않습니다.
* 기존 주문 등의 참조를 위해 상품 데이터는 유지합니다.

---

## 4. 권한 (Permissions)

* **Super Admin**: 모든 상품 조회 및 관리
* **Store Operator**: 허용된 상품 조회 및 관리
* **Customer**: 상품 조회만 가능하며 관리 기능은 사용할 수 없습니다.

---

## 5. 비기능 요구사항 (Non-Functional Requirements)

### 5.1 접근 제어

* 상품 관리 API는 어드민 권한을 가진 사용자만 사용할 수 있어야 합니다.
* Client API는 상품 조회 기능만 제공합니다.
* Client에서는 상품 데이터를 직접 수정할 수 없어야 합니다.

### 5.2 데이터 무결성

* 상품과 연결된 Item/SKU의 참조 관계를 유지해야 합니다.
* 기존 주문 등에서 참조되는 상품은 물리 삭제하지 않습니다.
* 상품 비활성화 이후에도 기존 데이터의 참조가 유지되어야 합니다.
