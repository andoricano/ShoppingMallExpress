# [PRD] 장바구니 및 주문서 작성 모듈 (Order)

## 1. 개요 (Overview)
본 문서는 소비자가 상품 탐색 후 장바구니/관심상품에 담고, 주문서를 작성하여 결제 단계로 진입하기까지의 구매 전반부(Client-centric) 요구사항을 다룹니다.

---

## 2. 관리 데이터 범위 (Data Scope)

### 2.1 장바구니 및 위시리스트 데이터
- **위시리스트**: User ID, Product ID, 등록 일시
- **장바구니**: Cart ID, User ID, Product ID, Option SKU ID, 수량, 선택 여부(Checked)

### 2.2 주문서 및 임시 주문 데이터
- **주문서 입력 정보**: 수령인 이름, 연락처, 배송지 주소, 픽업 여부/장소, 배송 요청사항
- **임시 주문 데이터**: Order ID, 주문 상태 (`결제대기`), 임시 재고 점유 만료 일시 (TTL)

---

## 3. 기능 요구사항 (Functional Requirements)

### 3.1 관심상품(위시리스트) 관리 (Client)
- **등록/삭제**: 소비자가 마음에 드는 상품의 하트 아이콘을 토글하여 관심상품 목록에 추가 및 삭제
- **목록 조회**: 마이페이지 내 관심상품 모아보기 및 장바구니 바로 이동 기능 제공

### 3.2 장바구니 담기 및 관리 (Client)
- **담기 및 수정**: 상품 상세 페이지에서 옵션(사이즈, 색상 등)과 수량을 선택하여 장바구니에 저장
- **수량/옵션 변경**: 장바구니 화면 내에서 선택한 상품의 수량 조절 및 옵션 재선택
- **선택 삭제 및 일괄 삭제**: 장바구니 내 개별/선택 상품 삭제 기능

### 3.3 주문서 작성 (Client)
- **진입 경로**: 장바구니 선택 구매 또는 상품 상세 페이지의 '바로 구매'를 통해 주문서 진입
- **정보 입력**: 
  - 배송지 정보 (기본 배송지 불러오기, 신규 배송지 입력)
  - 픽업 선택 시 픽업 매장/시간 정보 지정
  - 수령인 정보 및 배송 요청사항 작성
- **결제금액 계산**: 총 상품금액 + 배송비 - 할인 금액 = 최종 결제 예정 금액 실시간 산출

### 3.4 주문 생성 및 재고 임시 점유 (System Engine)
- **주문 ID 발급**: 소비자가 '결제하기' 버튼 클릭 시 미결제 상태의 `Order ID` 생성
- **재고 선점 (Hold)**: 이중 결제 방지를 위해 해당 옵션 SKU의 재고를 일정 시간(예: 10분) 동안 임시 점유
- **점유 해제**: 이탈 또는 시간 초과 시 선점된 재고 자동 원복

### 3.5 결제 상태 확인 대기 (System Engine)
- **이벤트 수신**: 결제 모듈(PG)로부터 '결제 완료' 이벤트를 비동기로 전달받음
- **상태 자동 전환**: 주문 상태를 `[결제대기] -> [주문접수]`로 자동 변경 후 주문 완료 화면으로 리다이렉트
