# [PRD] 전체 쇼핑몰 SaaS 시스템 모듈 정의서

## 1. 시스템 아키텍처 개요 (System Overview)

본 시스템은 **11개 핵심 모듈**이 서로 연동되어 작동하는 E-Commerce SaaS 플랫폼입니다.
회원 인증부터 상품, 주문, 결제, 물류, CS 및 알림까지의 전체 데이터 흐름(End-to-End)을 관리합니다.

---

## 3. 모듈별 세부 기능 요구사항 (Detailed Functional Requirements)

### 3.1 회원 인증 모듈 (Auth & User Management)
- **회원 가입 및 로그인**: 이메일/비밀번호 기반 가입 및 JWT 토큰 인증
- **권한 관리 (RBAC)**: 구매자(Client), 판매자(Seller), 총괄 관리자(Super Admin) 권한 분리
- **마이페이지**: 회원 정보 수정, 배송지 목록 관리, 회원 탈퇴(Soft Delete)

### 3.2 재고 관리 모듈 (Inventory Management)
- **SKU 원천 재고 관리**: 바코드/SKU 단위 실재고 등록 및 차감
- **재고 연동**: 주문 발생 시 실시간 재고 선점(Hold) 및 결제 완료 시 최종 차감
- **안전 재고 알림**: 설정된 안전 재고 미만 도달 시 판매자 알림 트리거

### 3.3 상품 관리 모듈 (Product Management)
- **상품 Master 등록**: 원천 재고(SKU)를 매핑하여 판매용 상품 등록/수정/삭제
- **카테고리 및 할인**: 계층형(대/중/소) 카테고리 트리 및 상품 단위 정률/정액 할인 적용
- **전시 및 소진 처리**: 진열 상태(`진열`, `숨김`, `품절`, `삭제`) 제어 및 실시간 차단

### 3.4 주문 기능 모듈 (Order Engine)
- **장바구니 및 위시리스트**: 상품 선택, 옵션 변경, 수량 조절 및 구매 대기 목록 저장
- **주문서 작성**: 배송지 선택, 쿠폰/포인트 적용, 최종 결제 금액 산정
- **주문 생성**: 주문 고유 번호(Order ID) 생성 및 주문 상태 초기화 (`주문 접수`)

### 3.5 결제 모듈 (Payment Engine)
- **PG 연동**: 신용카드, 계좌이체, 가상계좌, 간편결제(카카오페이/네이버페이 등) 연동
- **결제 검증**: 주문서 금액과 실제 PG 결제 요청 금액 일치 여부 위변조 검증
- **결제 취소**: 환불 요청 시 PG 승인 취소 API 호출 및 가상계좌 환불 처리

### 3.6 주문 이력 관리 모듈 (Order History & Claim)
- **주문 내역 조회**: 구매자/판매자별 주문 상태(`결제완료`, `배송준비`, `배송중`, `배송완료`) 추적
- **클레임 처리 (CS)**: 주문 취소, 교환 신청, 반품 접수 및 승인/거절 라이프사이클 관리

### 3.7 리워드 모듈 (Rewards & Loyalty)
- **포인트/적립금**: 구매 확정 시 일정 비율 적립, 주문 시 현금성 차감 결제
- **쿠폰 관리**: 정급/다운로드 쿠폰 발행, 최소 주문 금액 및 최대 할인 금액 제어

### 3.8 물류 기능 모듈 (Logistics & WMS)
- **출고 지시**: `결제 완료` 주문 건의 출고 요청 데이터 물류 창고 전송
- **송장 관리**: 택배사 연동을 통한 운송장 번호 일괄/개별 입력 및 상태 업데이트

### 3.9 배송 알림 모듈 (Notification System)
- **트리거 알림**: 주문 완료, 결제 확인, 출고 시작, 배송 완료 시 알림 발송
- **채널 관리**: 카카오 알림톡, SMS, 앱 PUSH 알림 연동 및 발송 이력 기록

### 3.10 문의 시스템 모듈 (Inquiry & CS)
- **상품 Q&A**: 상품 상세 페이지 내 공개/비공개 문의 작성 및 답변 연동
- **1:1 고객 문의**: 주문건 매핑 1:1 문의 접수, 파일 첨부, 관리자 답변 완료 알림

### 3.11 SNS 연동 모듈 (SNS Integration)
- **소셜 로그인**: 카카오, 네이버, 구글, Apple OAuth 2.0 간편가입/로그인
- **소셜 공유**: 상품 상세 URL/이미지 카카오톡 및 SNS 공유하기 기능
- **마케팅 피드**: Meta Pixel, Google Analytics 데이터 트래킹 픽셀 연동

## 4. 비기능 요구사항 (Non-Functional Requirements)

- **트랜잭션 일관성 (SAGA Pattern / Event-Driven)**:
  - 주문-결제-재고 차감 간 트랜잭션 실패 시 보상 트랜잭션(Automatic Rollback) 실행
- **알림 및 로깅 처리 (Async Processing)**:
  - 배송 알림 및 SNS 연동 로직은 메시지 큐(Message Queue)를 이용해 비동기 처리하여 주문/결제 성능 지연 방지
