# [PRD] 주문 사용자 (Order Client None)

> 본 문서는 인증되지 않은 사용자의 주문 생성, 주문 조회, 배송 완료 확정 및 주문 대상 상품 선택 기능을 정의합니다.
>
> 주문 데이터 구조는 `Order_Summary`, 주문 관리 및 출고 처리는 `Order_Admin`을 기준으로 합니다.

---

## 1. 주문 생성

비회원 사용자는 결제를 완료한 후 주문 생성을 요청합니다.

```text
Product
   ↓
배송 정보 입력
   ↓
결제
   ↓
Payment 완료
   ↓
Order 생성 요청
```

비회원 사용자는 다음 정보를 기준으로 주문을 요청합니다.

```text
Payment ID
Product ID
주문 수량
배송지
주문자 정보
```

주문자 정보는 다음 정보를 포함합니다.

```text
주문자 이름
연락처
```

서버는 Product와 Inventory를 확인하여 주문 데이터를 구성합니다.

비회원 사용자가 상품명, 가격, SKU Code, Inventory 등의 주문 데이터를 직접 결정할 수 없습니다.

---

## 2. 주문 대상 상품

주문은 하나 이상의 Product를 대상으로 생성할 수 있습니다.

주문 대상 상품은 다음 경로에서 선택할 수 있습니다.

```text
장바구니
   ↓
주문 상품 선택
   ↓
Order

상품 페이지
   ↓
바로 구매
   ↓
Order
```

장바구니에서 일부 상품만 선택하여 주문할 수 있습니다.

상품 페이지에서 바로 구매하는 경우 기존 장바구니 상품과 별도로 주문할 수 있습니다.

기존 장바구니 상품을 함께 주문할지는 사용자가 선택합니다.

---

## 3. 주문 조회

비회원 사용자는 **자신이 생성한 주문만 조회할 수 있습니다.**

비회원 주문 조회를 위해 주문 생성 시 서버가 **비회원 주문 접근용 인증 정보**를 발급합니다.

```text
주문 생성
   ↓
Guest Order Access Token 발급
   ↓
주문 완료 시 사용자에게 전달
   ↓
주문 조회 API
   ↓
Token 검증
   ↓
해당 주문 조회
```

비회원 주문 조회 시 다음 정보를 확인할 수 있습니다.

### 주문 목록

비회원 주문에서는 별도의 전체 주문 목록을 제공하지 않고, 발급된 주문 접근 정보를 통해 개별 주문을 조회합니다.

### 주문 상세

* 주문 정보
* 주문 상품 및 Snapshot
* 배송지
* 배송 정보
* 주문 상태
* 주문 금액
* 주문 일시

발급된 인증 정보로 다른 비회원 주문을 조회할 수 없습니다.

---

## 4. 배송 완료 확정

`SHIPPING` 상태의 비회원 주문에 대해 사용자가 배송 완료를 확정할 수 있습니다.

```text
SHIPPING

   ↓

배송 완료 확정

   ↓

COMPLETED
```

배송 완료 확정 요청 시 해당 비회원 주문의 접근 권한을 확인합니다.

`COMPLETED` 또는 `CANCELLED` 상태에서는 배송 완료 확정을 수행할 수 없습니다.

---

## 5. Payment 연동

비회원 주문도 회원 주문과 동일하게 결제 완료 이후 주문을 생성합니다.

Order 생성 API는 `Payment ID`를 기준으로 결제 상태를 확인하며, 결제가 완료되지 않은 경우 주문을 생성하지 않습니다.

결제 처리 및 환불은 Payment 모듈에서 담당합니다.

---

## 6. 주문 접근 권한

비회원 사용자는 인증 계정이 존재하지 않으므로 Supabase Auth를 사용하지 않습니다.

대신 서버가 발급한 비회원 주문 접근 인증 정보를 사용하여 자신이 생성한 주문에 접근합니다.

```text
Guest Order Access Token
        ↓
Order API
        ↓
Token 검증
        ↓
해당 Order 접근
```

비회원 사용자는 다음 기능을 사용할 수 있습니다.

* 주문 생성
* 주문 상품 선택
* 주문 조회
* 배송 상태 확인
* 배송 완료 확정

비회원 사용자는 다른 주문의 조회 및 수정 권한을 가지지 않습니다.

주문 상태의 임의 변경은 허용하지 않습니다.

---

## 7. 회원 주문과의 차이

| 구분       | Order Client   | Order Client None        |
| :------- | :------------- | :----------------------- |
| 인증       | Supabase Auth  | 비회원 주문 접근 인증 정보          |
| 주문 식별    | `clientId`     | Guest Order Access Token |
| 프로필 연동   | Client Profile | 주문 시 입력한 주문자 정보          |
| 주문 조회    | 자신의 주문 목록/상세   | 접근 정보로 개별 주문 조회          |
| 주문 생성    | 가능             | 가능                       |
| 배송 완료 확정 | 가능             | 가능                       |
