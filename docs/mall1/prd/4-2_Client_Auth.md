# [PRD] Client 인증 및 프로필

> 본 문서는 쇼핑몰 Client의 인증, 프로필 및 기본 배송 정보 관리를 정의합니다.
>
> 인증은 Supabase Auth를 사용하며, Client의 주문, 장바구니 및 결제 기능은 각 모듈에서 별도로 정의합니다.

---

## 1. 개요

Client는 Google OAuth를 통해 쇼핑몰에 로그인할 수 있습니다.

인증과 Session 관리는 Supabase Auth를 사용하며, 로그인된 User의 기본 정보와 쇼핑몰 이용에 필요한 Client 정보를 관리합니다.

```text
Google OAuth
   ↓
Supabase Auth
   ↓
Client 인증
   ↓
서비스 이용
```

로그인 자체는 필수 인증 절차이며, 프로필 및 배송 정보 입력은 필요한 시점에 진행할 수 있습니다.

---

## 2. 사용자 정보

### 2.1 기본 정보

Supabase Auth를 통해 다음 정보를 확인합니다.

```text
User ID
Email
Name
```

`User ID`는 Supabase Auth의 User ID를 사용합니다.

### 2.2 Client 정보

쇼핑몰 이용 과정에서 다음 정보를 관리할 수 있습니다.

```text
수령인 이름
연락처
기본 배송지
```

기본 배송지는 다음 정보를 포함합니다.

```text
우편번호
주소
상세 주소
```

---

## 3. Google 로그인

Client는 Google OAuth를 통해 로그인합니다.

```text
로그인
   ↓
Google OAuth
   ↓
Supabase Auth
   ↓
로그인 완료
```

OAuth 인증이 완료되면 Supabase Auth Session을 유지합니다.

OAuth 인증이 취소되거나 실패한 경우 로그인 화면에서 다시 인증할 수 있어야 합니다.

---

## 4. 로그인 후 Client 정보

Google 로그인만 완료한 Client도 기본적인 쇼핑몰 서비스를 이용할 수 있습니다.

추가 프로필 및 배송 정보는 회원가입 직후 강제로 입력하지 않습니다.

```text
로그인
   ↓
쇼핑몰 이용
   ↓
필요한 시점에 Client 정보 입력
```

Client는 상품을 둘러보거나 장바구니를 이용한 후, 주문 과정에서 필요한 배송 정보를 입력할 수 있습니다.

---

## 5. Client 프로필

Client는 자신의 프로필 정보를 조회하고 수정할 수 있습니다.

관리 대상 정보:

```text
Name
Email
수령인 이름
연락처
기본 배송지
```

Client는 자신의 정보만 조회 및 수정할 수 있습니다.

다른 Client의 프로필 정보에는 접근할 수 없습니다.

---

## 6. 기본 배송지

Client는 주문에 사용할 기본 배송지를 관리할 수 있습니다.

```text
기본 배송지
├─ 수령인 이름
├─ 연락처
├─ 우편번호
├─ 주소
└─ 상세 주소
```

배송 정보는 회원가입 시 필수로 입력하지 않습니다.

주문 생성 과정에서 배송 정보가 필요한 경우 Client가 입력할 수 있으며, 입력한 배송 정보를 기본 배송지로 저장하여 이후 주문에서 재사용할 수 있습니다.

```text
주문
   ↓
배송지 입력
   ├─ 이번 주문에만 사용
   │
   └─ 기본 배송지로 저장
```

주문에 저장되는 배송지는 주문 생성 시점의 정보를 별도로 보존합니다.

---

## 7. Client 프로필 API

Client는 자신의 프로필 정보를 조회하고 수정할 수 있습니다.

### 조회

```text
GET /api/client/profile
```

현재 로그인한 Client의 프로필 정보를 반환합니다.

### 수정

```text
PATCH /api/client/profile
```

현재 로그인한 Client의 프로필 및 기본 배송 정보를 수정합니다.

Client는 자신의 프로필만 수정할 수 있습니다.

`role` 등의 권한 정보는 Client API를 통해 수정할 수 없습니다.

---

## 8. 인증 상태

Client의 인증 상태는 Supabase Auth Session을 기준으로 판단합니다.

```text
인증 안됨
   ↓
Google 로그인
   ↓
인증됨
```

인증이 필요한 기능에 비로그인 상태로 접근하는 경우 로그인 화면으로 이동합니다.

---

## 9. 로그아웃

Client는 로그아웃할 수 있습니다.

로그아웃 시 Supabase Auth Session을 종료합니다.

```text
로그아웃
   ↓
Session 종료
   ↓
비로그인 상태
```

---

## 10. 권한

Client는 자신의 데이터에 대해서만 접근할 수 있습니다.

```text
자신의 프로필 조회
자신의 프로필 수정
자신의 기본 배송지 조회
자신의 기본 배송지 수정
자신의 주문 조회
자신의 주문 생성
자신의 장바구니 접근
```

다른 Client의 데이터에 대한 접근은 허용하지 않습니다.

Client의 주문 및 장바구니 상세 정책은 각각 `Order_Client`, `Cart` 관련 모듈에서 정의합니다.
