# [PRD] 상품 관리 모듈 (Product Management) - 판매자 중심 (Admin Focused)

## 1. 개요 (Overview)
본 문서는 쇼핑몰 SaaS의 **판매자 어드민(Admin) 중심 상품 관리 모듈**에 대한 PRD입니다. 
원천 재고 모듈 데이터를 기반으로 판매 상품을 등록·수정·삭제하고, 계층형 카테고리 및 할인 정책을 관리하며, 구매자 쇼핑몰 채널에는 **어드민이 지정한 조건에 맞추어 단방향 노출(Read-Only)**을 제공하는 것을 목표로 합니다.

---

## 2. 관리 데이터 범위 (Data Scope)

### 2.1 상품 마스터 데이터 (Product Master Data)
- **기본 정보**: 상품 ID (Product ID), 상품명, 대표/추가 이미지, 상세 설명 (HTML/MD), 판매 상태 (`진열중`, `숨김`, `품절`, `삭제됨`), 진열 우선순위 (Sort Order)
- **가격 정보**: 정상가 (Base Price), 판매가 (Discounted Price), 할인율 (%), 할인 기간 (시작/종료일시)
- **옵션 및 재고 매핑**: 옵션 조합 (색상, 사이즈 등), 옵션별 추가 금액 (Option Surcharge), 매핑된 SKU ID (`SkuInventory.id`) 목록

### 2.2 카테고리 및 알림 데이터
- **카테고리 ID**: 계층 구조 (대분류 > 중분류 > 소분류), 노출 순서
- **판매자 알림 데이터**: 품절/재고 임박, 판매 급증 알림 이력 및 읽음 상태

---

## 3. 기능 요구사항 (Functional Requirements)

### 3.1 상품 등록 (Admin Only)
- **원천 재고 매핑**: `재고 모듈`에 등록된 SKU 데이터(`SkuInventory.id`)를 기반으로 판매용 상품 옵션을 구성하고 생성합니다.
- **주요 입력 항목**: 상품명, 대표/추가 이미지, 상세 설명, 기본 가격, 옵션별 추가 금액, 카테고리 매핑, 진열 순서
- **노출 채널 설정**: 초기 노출 여부 (`진열중` / `숨김`) 지정

### 3.2 상품 목록 및 상세 조회 (Admin & Client Read-Only)
- **Admin UI**:
  - 전체 상품 목록, 진열 상태, 카테고리, 가격, 옵션별 재고 상태 검색 및 상세 조회
  - 필터: 카테고리, 판매 상태 (`진열중`/`숨김`/`품절`/`삭제됨`), 상품명/코드 검색
  - **일괄 관리 (Batch Action)**: 다중 상품 선택 후 진열 상태 일괄 변경 (`진열중` ↔ `숨김`) 및 카테고리 일괄 이동
- **Client UI (Read-Only Exhibition)**:
  - 어드민에서 관리하는 상품 및 카테고리 데이터를 기반으로 한 목록/상세 단순 조회 API 제공
  - 정렬 기준 제공: 추천순(상단고정), 신상품순, 인기순, 가격순
  - `숨김` 또는 `삭제됨` 상태의 상품은 조회 결과에서 원천 제외

### 3.3 상품 정보 수정 (Admin Only)
- **수정 범위**: 상품명, 이미지, 상세 설명, 카테고리, 할인 정책, 옵션 구성 및 추가금 등 수정 가능
- **실시간 반영**: 수정 즉시 클라이언트 전시 API 조회 데이터에 반영

### 3.4 상품 삭제 및 노출 차단 (Soft Delete - Admin Only)
- **삭제 방식**: DB 물리 삭제 대신 `삭제됨 (DELETED)` 상태로 처리 (기존 주문/결제 내역과의 참조 무결성 유지)
- **즉시 노출 차단**: 삭제 처리된 상품은 클라이언트 화면에서 즉시 조회 불가 처리
- **Direct URL 차단**: 삭제된 상품 상세 접근 시 "존재하지 않거나 삭제된 상품입니다" 안내 후 메인 이동

### 3.5 계층형 카테고리 트리 관리 (Admin & Client Read-Only)
- **카테고리 관리 (Admin Only)**: 대/중/소 계층형 트리 구조의 카테고리 생성, 수정, 순서 변경, 삭제
- **상품 매핑 (Admin Only)**: 1개의 상품을 1개 이상의 카테고리에 다중 매핑 가능
- **카테고리 트리 제공 (Client Read-Only)**: 구매자 화면 메뉴(GNB/LNB) 구성을 위한 카테고리 트리 단순 조회 API 제공

### 3.6 상품 할인 시스템 (Admin Only Control)
- **할인 설정 (Admin Only)**: 
  - 할인 유형: 정률 할인 (%), 정액 할인 (원) 선택
  - 할인 기간: 시작/종료 일시 지정 (예약 할인 지원)
- **가격 표기 (Client Read-Only)**: 
  - 어드민 설정 기간 내 접근 시 계산된 할인 판매가 및 할인율 단순 표기

### 3.7 판매자 상품 알림 시스템 (Admin Only)
- **품절 및 재고 임박 알림**: 특정 상품의 전 옵션/SKU 재고가 0이 되거나 안전재고 이하 달성 시 관리자 알림 발송 및 대시보드 노출
- **판매 급증 알림**: 특정 시간 내 설정 수량 이상 판매 발생 시 대시보드 내 "주요 상품 알림" 위젯 노출

---

## 4. 비기능 요구사항 (Non-Functional Requirements)

- **성능 및 캐싱 (Performance)**:
  - 상품 삭제 및 수정 발생 시 전시용 API 캐시를 즉시 무효화(Invalidation)하여 실시간 노출 차단 보장
- **데이터 무결성**:
  - 삭제된 상품이더라도 기존 완료된 주문 내역 및 결제 영수증에서는 삭제 당시의 상품 정보가 그대로 유지되도록 처리
