# [PRD] SNS 연동 및 공유 모듈 (SNS Integration & Social Sharing)

## 1. 개요 (Overview)
본 문서는 쇼핑몰 SaaS의 SNS 연동 및 공유 모듈에 대한 PRD입니다. 
상품 및 쇼핑몰 내 게시글/콘텐츠의 고유 공유 URL을 생성하고, 주요 SNS 플랫폼(카카오톡, 페이스북, X, 인스타그램 등) 공유 시 미리보기 카드(제목, 설명, 섬네일 이미지)가 정교하게 노출되도록 메타데이터(Open Graph) 및 공유 기능을 제공하는 것을 목표로 합니다.

---

## 2. 관리 데이터 범위 (Data Scope)

### 2.1 메타데이터 (Open Graph / Meta Tags)
- **OG 메타 정보**: OG Title (제목), OG Description (설명), OG Image (섬네일 URL), OG URL (원본 주소)
- **기본 브랜드 이미지**: 상품/게시글별 전용 이미지가 없을 때 노출할 쇼핑몰 대표 기본 섬네일 URL

### 2.2 공유 링크 데이터 (Shareable Link)
- **고유 URL / 딥링크**: 상품 ID (`Product ID`) 또는 게시글 ID (`Post ID`) 매핑 고유 URL
- **마케팅 파라미터**: 유입 경로 추적용 UTM 파라미터 (`utm_source`, `utm_medium`, `utm_campaign`)

---

## 3. 기능 요구사항 (Functional Requirements)

### 3.1 SNS 공유 미리보기 정보 제공 (Meta Tag Engine)
- **Open Graph (OG) 자동 생성**:
  - 상품/게시글 상세 페이지 진입 시 크롤러(SNS 로봇)가 읽을 수 있는 OG 태그 (`og:title`, `og:description`, `og:image`, `og:url`) 자동 동적 생성
- **플랫폼별 최적화 규격**: 카카오톡, 페이스북, 텔레그램 등 주요 SNS 플랫폼의 스크랩 규칙에 적합한 메타 규격 준수

### 3.2 SNS 공유 고유 링크 생성 (Link Generator)
- **고유 주소 및 단축 URL**: 상품 및 콘텐츠별 고유 랜딩 URL을 생성하여 SNS 클릭 시 해당 상세 페이지로 직접 이동 처리
- **유입 추적 파라미터 바인딩**: SNS 공유 버튼으로 생성된 링크에 유입 채널 분석용 UTM 파라미터를 선택적으로 자동 결합

### 3.3 상품 SNS 공유 (Client UI)
- **공유 버튼 인터페이스**: 상품 상세 페이지 내 'SNS 공유하기' 레이어/팝업 제공
- **지원 채널**: 카카오톡 (카카오링크 API 연동), 링크 복사 (URL Copy), 페이스북, X (구 트위터) 등 주요 SNS 버튼 연동
- **공유 실행**: 클릭 시 해당 상품의 상품명, 할인가, 대표 이미지가 담긴 프리뷰 카드 형태로 SNS 공유 실행

### 3.4 게시글/콘텐츠 SNS 공유 (Client UI)
- **콘텐츠 공유 인터페이스**: 쇼핑몰 내 공지사항, 프로모션 이벤트, 블로그/매거진 게시글 상세 페이지 내 공유 버튼 제공
- **콘텐츠 메타 연결**: 게시글의 제목, 요약글, 대표 이미지를 SNS 프리뷰 카드로 자동 파싱하여 전송

### 3.5 공유 대상별 대표 이미지 설정 (Admin Only)
- **어드민 기본 섬네일 관리**: 
  - 쇼핑몰 대표 기본 공유 이미지 등록 (상품/게시글 개별 이미지가 누락된 경우 대체 노출)
  - 상품 등록/수정 시 SNS 공유 전용 이미지 별도 지정 가능 (미지정 시 상품 대표 이미지 자동 채택)
  - 게시글 등록/수정 시 콘텐츠 전용 공유 이미지 별도 지정 가능

---

## 4. 비기능 요구사항 (Non-Functional Requirements)

- **SNS 크롤러 캐시 대응 (OG Cache Refresh)**:
  - 상품명, 이미지, 가격 수정 시 각 SNS 플랫폼(카카오, 메타 등)의 OG 캐시 갱신/무효화 처리 가이드 및 API 연동 고려
- **클립보드 보안 및 호환성**:
  - 모바일 및 웹 브라우저 환경에서 'URL 복사' 기능 수행 시 HTTPS 보안 프로토콜 상에서 안전하게 클립보드 복사 처리
